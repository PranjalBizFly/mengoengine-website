## 4. Internal linking graph

```
Homepage
   |
   +-- Platform hub --> Product --> Features --> Use cases
   |                       |            |
   |                       v            v
   +-- Solutions -----> Industries --> Channels --> Channel x industry
   |        |               |              |
   |        v               v              v
   +-- Comparisons     Use cases      Asset formats
   |
   +-- Resources --> Glossary --> Blog --> Blog topic
```

Every arrow is generated by `link()` in `src/lib/registry.ts` from slug references in the data, and rendered by `RelatedRail`. Breadcrumbs follow the URL hierarchy and are mirrored into `BreadcrumbList` structured data on every page below the homepage.
